# Mawon Freedom Arts website

Live at https://mawonfreedomarts.com/ (GitHub Pages). Owner: Roth$child (Rothschild J. Toussaint). He is not a developer: he describes changes in plain words, often with photos attached, and expects them built, checked and launched.

## How changes are made

1. Edit `tools/build.py` (and `assets/css/site.css`, `assets/js/*.js` for styling and behavior). Every page's HTML is generated by the build script, so don't hand-edit the generated `index.html` files: the next build would overwrite them.
2. Run `python3 tools/build.py`.
3. Check the result: serve locally with `python3 -m http.server`, screenshot changed pages at desktop (1440px) and phone (390px) widths, confirm no console errors, no horizontal scroll and no broken internal links. Show the owner screenshots of anything visual.
4. Commit, open a pull request into `main`, and merge it when checks pass. The owner has asked for changes to be launched this way; ask first if a change is large or ambiguous.
5. The `Publish site` workflow copies `main` to `gh-pages`, and GitHub Pages deploys it within a minute or two. Confirm the "pages build and deployment" run succeeds.

## Rules the owner set

- Black and white. Photos are converted to black and white: a full size (up to 1600px wide) plus a `-sm` size (800px wide), saved as JPEG in `assets/img/`.
- No em dashes in site copy, and plain, natural wording.
- The owner's own words stay verbatim, typos included: the bio (`BIO` in `tools/build.py`) and the writing in `tools/pieces/*.json`. Never edit them unless he asks.
- Kreyòl labels accompany the English ones (About / istwa, Music / mizik, Writing / ekri, Photos / foto, Contact / pale).
- Home page: five 3D congas in a half circle with Music (96 EYZ emblem) in the middle. Drum order, size and pitch live in `DRUM_LINKS`.
- Brand marks in use: the MAW◎N wordmark, the seal, and the 96 EYZ emblem.

## Things that must not break

- `CNAME` (contents: `mawonfreedomarts.com`) must stay at the root of `main`. The publish workflow refuses to run without it; removing it would disconnect the domain.
- `SITE` in `tools/build.py` is `https://mawonfreedomarts.com/`. The sitemap, canonical links, share previews and structured data use it.
- The contact form uses FormSubmit (`Rothschild859@gmail.com`). It already works on mawonfreedomarts.com.
- three.js is vendored in `assets/vendor/`, and the fonts are self-hosted in `assets/fonts/`. No CDNs.

## Adding content

- **Writing:** copy `tools/pieces/writing-my-wrongs.json`, fill it in verbatim, and run the build. The newest piece leads the Writing page and gets its own reading page.
- **Photos:** add both image sizes to `assets/img/`, then add a `shot(...)` line in the Photos section of `tools/build.py`.
- **Links:** profile URLs are constants at the top of `tools/build.py` (Instagram ×2, X, Linktree, Substack, Spotify, Apple Music, YouTube, SoundCloud).
